Sentencias de control

Las sentencias de control son estructuras que permiten controlar el flujo de ejecución de un programa.

Esto permite que el programa pueda:

  • Tomar decisiones
  • Repetir instrucciones
  • Ejecutar diferentes caminos según una condición

Son esenciales para crear aplicaciones dinámicas, interactivas y funcionales, especialmente en el desarrollo web y la programación visual.

Sentencias condicionales

Permiten ejecutar un bloque de código solo si se cumple una condición determinada.
