Sentencias de control


Las sentencias de control son estructuras que permiten controlar el flujo de ejecución de un programa.

Esto permite que el programa pueda:

  • Tomar decisiones
  • Repetir instrucciones
  • Ejecutar diferentes caminos según una condición

Son esenciales para crear aplicaciones dinámicas, interactivas y funcionales, especialmente en el desarrollo web y la programación visual.


Sentencias condicionales

Sentencias if - else - else if

Permiten ejecutar un bloque de código solo si se cumple una condición determinada.

Sentencia switch

Se usa cuando hay varias opciones posibles según un valor.


Sentencias de Repetición (Bucles)

Las sentencias de repetición, también conocidas como bucles, permiten ejecutar un bloque de código varias veces mientras se cumpla una condición determinada.


Ejercicios practicos

Ejercicio 1: Precio de entrada según la edad

Escribir un programa para una empresa que tiene salas de juegos y que calcule el precio de la entrada según la edad del cliente: Menores de 4 años → Entrada gratuita; Entre 4 y 18 años → $5 ; Mayores de 18 años → $10 


print("Ingrese la edad del cliente: ")
val edad = readLine()!!.toInt()

if (edad < 4) {
    println("La entrada es gratuita")
} else if (edad <= 18) {
    println("El precio de la entrada es $5")
} else {
    println("El precio de la entrada es $10")
}

Ejercicio 2: Números impares hasta un número dado

Escribir un programa que pida un número entero positivo y muestre todos los números impares desde 1 hasta ese número, separados por comas. 


print("Ingrese un número entero positivo: ")
val numero = readLine()!!.toInt()

for (i in 1..numero step 2) {
    if (i < numero) {
        print("$i, ")
    } else {
        print(i)
    }
}
