¿Qué es una expresión?

Una expresión es una estructura formada por operandos (valores o variables) y operadores, que al ser evaluada por el programa produce un valor final. Ese valor puede almacenarse en una variable, utilizarse en una condición o retornarse desde una función.

En términos generales, las expresiones representan la lógica del programa, ya que permiten:

  • Realizar cálculos matemáticos
  • Comparar información
  • Evaluar condiciones lógicas
  • Tomar decisiones programáticas
  • Generar resultados dinámicos

En muchos lenguajes modernos, como Kotlin, incluso las estructuras de control pueden comportarse como expresiones, lo que hace el código más compacto y expresivo.

Componentes de una expresión

Componente Descripción Ejemplo
Operandos Valores o variables que participan en la operación 5, x, "texto"
Operadores Símbolos que indican la operación a realizar +, -, *, /, &&, ||
Resultado Valor final obtenido tras la evaluación 15, true, "Hola Mundo"

Tipos de Expresiones


Operadores

Los operadores son símbolos que le indican al programa que realice operaciones específicas sobre uno o más valores.

Operadores Aritméticos

Operador Nombre Descripción Ejemplo Resultado
+ Suma Suma dos valores 5 + 3 8
- Resta Resta el segundo valor del primero 10 - 4 6
* Multiplicación Multiplica dos valores 6 * 7 42
/ División Divide el primer valor entre el segundo 15 / 3 5
% Módulo Devuelve el residuo de la división 17 % 5 2

Ejemplo:

fun calcularDescuento(precio: Double, porcentaje: Double): Double {
    return precio * (porcentaje / 100)
}

val precioOriginal = 200.0
val descuento = calcularDescuento(precioOriginal, 15.0)  // 30.0
val precioFinal = precioOriginal - descuento  // 170.0

Operadores Relacionales

Operador Nombre Descripción Ejemplo Resultado
== Igualdad Verdadero si los valores son iguales 5 == 5 true
!= Desigualdad Verdadero si los valores son diferentes 5 != 3 true
> Mayor que Verdadero si el primero es mayor 10 > 5 true
< Menor que Verdadero si el primero es menor 3 < 7 true
>= Mayor o igual Verdadero si el primero es mayor o igual 5 >= 5 true
<= Menor o igual Verdadero si el primero es menor o igual 4 <= 4 true

Ejemplo:

fun main() {
    val a = 10
    val b = 20

    println(a == b)   // false
    println(a != b)   // true
    println(a >= 10)  // true
    println(b <= 15)  // false
}

Operadores Lógicos

Operador Nombre Descripción Ejemplo Resultado
&& AND (Y lógico) Verdadero si AMBAS condiciones son verdaderas true && false false
|| OR (O lógico) Verdadero si AL MENOS UNA condición es verdadera true || false true
! NOT (Negación) Invierte el valor booleano !true false

Ejemplo práctico:

fun verificarAcceso(edad: Int, tienePermiso: Boolean, esEmpleado: Boolean): Boolean {
    // Puede acceder si:
    // 1. Es mayor de edad Y tiene permiso
    // 2. O si es empleado (sin importar edad o permiso)
    return (edad >= 18 && tienePermiso) || esEmpleado
}

val acceso1 = verificarAcceso(20, true, false)   // true
val acceso2 = verificarAcceso(16, true, true)    // true (es empleado)
val acceso3 = verificarAcceso(16, false, false)  // false

Operadores de Incremento y Decremento

Estos operadores permiten aumentar o disminuir el valor de una variable en una unidad o en una cantidad específica de forma concisa.

Incremento

var contador = 5
contador++      // Aumenta en 1: contador = 6
contador += 3   // Aumenta en 3: contador = 9

Decremento

var numero = 10
numero--       // Disminuye en 1: numero = 9
numero -= 2    // Disminuye en 2: numero = 7

Ejercicio 1: Área del círculo y volumen del cilindro


Escribir una función que calcule el área de un círculo y otra que calcule el volumen de un cilindro, utilizando la primera función.

Solución

  • Paso 1: Definir la función del área del círculo
    Creamos una función que reciba el radio.
  • Paso 2: Calcular el área del círculo
    Usamos la fórmula: π × radio².
  • Paso 3: Retornar el área
    Devolvemos el valor calculado.
  • Paso 4: Definir la función del volumen
    Creamos una función con radio y altura.
  • Paso 5: Calcular el volumen
    El volumen de un cilindro se calcula con la fórmula: V= área del círculo × altura. Se reutiliza la función del área del círculo.
  • Paso 6: Retornar el resultado
    Usamos return para devolver el volumen.

Código

import kotlin.math.PI
import kotlin.math.pow

// Función para calcular el área de un círculo
fun areaCirculo(radio: Double): Double {
    return PI * radio.pow(2)
}

// Función para calcular el volumen de un cilindro usando el área del círculo
fun volumenCilindro(radio: Double, altura: Double): Double {
    val areaBase = areaCirculo(radio)
    return areaBase * altura
}

Ejercicio 2: Factorial de un número


Escribir una función que calcule el factorial de un número.

Solución

  • Paso 1: Definir la función
    Creamos una función con un parámetro entero.
  • Paso 2: Calcular el factorial
    Multiplicamos los números desde 1 hasta n. Usamos una estructura condicional para calcular el factorial.
  • Paso 3: Retornar el resultado
    Usamos return para devolver el factorial.

Código

fun factorial(n: Int): Int {
    var resultado = 1
    for (i in 1..n) {
        resultado *= i
    }
    return resultado
}

Ejercicio 3: Distancia recorrida


Escribir una función que calcule la distancia recorrida por un objeto.

Solución

  • Paso 1: Definir la función
    Creamos una función con dos parámetros: velocidad y tiempo.
  • Paso 2: Calcular la distancia
    La distancia se calcula multiplicando la velocidad por el tiempo.
  • Paso 3: Retornar el resultado
    Usamos return para devolver la distancia recorrida.

Código

fun calcularDistancia(velocidad: Double, tiempo: Double): Double {
    val distancia = velocidad * tiempo
    return distancia
}

// Uso de la función
fun main() {
    val resultado = calcularDistancia(60.0, 2.0)
    println("Distancia recorrida: $resultado km")
}

Ejercicio 5: Calculadora de IMC


Crear una función que calcule el Índice de Masa Corporal (IMC) y determine la categoría correspondiente.

Solución

  • Paso 1: Definir la función
    Creamos una función que reciba el peso (kg) y la altura (m) como parámetros.
  • Paso 2: Calcular el IMC
    Usamos la fórmula: peso / (altura × altura).
  • Paso 3: Determinar la categoría
    Utilizamos expresiones condicionales para clasificar el IMC.
  • Paso 4: Retornar el resultado
    Retornamos el IMC y la categoría usando un objeto Pair.

Código


fun calcularIMC(peso: Double, altura: Double): Pair {
    val imc = peso / (altura * altura)

    val categoria = when {
        imc < 18.5 -> "Bajo peso"
        imc < 25.0 -> "Peso normal"
        imc < 30.0 -> "Sobrepeso"
        else -> "Obesidad"
    }

    return Pair(imc, categoria)
}

// Uso de la función
fun main() {
    val (imc, categoria) = calcularIMC(70.0, 1.75)
    println("IMC: ${String.format(\"%.2f\", imc)}")
    println("Categoría: $categoria")
}


Resumen Final

Expresiones

Las expresiones permiten representar operaciones y decisiones en el código.

Operadores

Los operadores construyen la lógica del programa mediante operaciones aritméticas, relacionales y lógicas.

Funciones

Las funciones encapsulan expresiones para reutilizar código y organizar la lógica del programa.

package app.compose.textreutilizable.ui
@Composable
//Text
fun TextUi(titulo: String, gradient: List) {
    Box(
        modifier = Modifier
            .fillMaxWidth()
            .background(
                brush = Brush.horizontalGradient(gradient)

            )
            .padding(20.dp),
        contentAlignment = Alignment.Center
    ) {
        Text(
            text = titulo,
            color = Color.White,
            fontSize = 22.sp,
            textAlign = TextAlign.Center,
            fontWeight = FontWeight.Bold
        )
    }
}
    // TEXTFIELD REUTILIZABLE de Calculadora
    @Composable
    fun CampoTexto(valor: String, etiqueta: String, onChange: (String) -> Unit) {
        TextField(
            value = valor,
            onValueChange = { nuevoValor ->
                if (nuevoValor.matches(Regex("^\\d*\\.?\\d*$"))) {
                    onChange(nuevoValor)
                }
            },
            label = { Text(etiqueta) },
            modifier = Modifier.fillMaxWidth(),
            keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Number),
            colors = TextFieldDefaults.colors(
                focusedContainerColor = Color(0xFFFAFAFA),
                unfocusedContainerColor = Color(0xFFFAFAFA),
                focusedTextColor = Color.Black,
                unfocusedTextColor = Color.Black
            )
        )
    }

    // BOTÓN REUTILIZABLE
    @Composable
    fun BotonOperacion(texto: String, gradient: List, accion: () -> Unit) {
        //se cambio Button a Box para poder usar degradado
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(55.dp)
                .background(
                    brush = Brush.horizontalGradient(gradient),
                    shape = RoundedCornerShape(30.dp)
                )
                .clickable { accion() },
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = texto,
                color = Color.White,
                fontWeight = FontWeight.Bold
            )

        }
        Spacer(Modifier.height(15.dp))
    }

    fun toDouble(texto: String): Double {
        return texto.toDoubleOrNull() ?: 0.0
    }

    class OpcionesCalculadora {

        fun sumar(a: Double, b: Double): Double = a + b

        fun restar(a: Double, b: Double): Double = a - b

        fun multiplicar(a: Double, b: Double): Double = a * b

        fun dividir(a: Double, b: Double): String {
            return if (b != 0.0) {
                (a / b).toString()
            } else {
                "Error: división entre 0"
            }
        }
    }
